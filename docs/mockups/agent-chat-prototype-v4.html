思考过程
1无头像、无署名行，助手消息直接以内容开始。
2思考块 逐字流出，想完自动合拢，可手动点开再看。
3✎ 工具卡片 实时显示进度（第几段 / 总进度 x/20），不占满窗口。
4正文流式输出 衬线字体逐字出现，每段写完即折叠成圆片，点圆片可偷看该段。
5全部完成后整体收进完成卡片：标题、摘要圆片、一句预览，点「展开」看全文。历史消息就是这个终态。
6⚡ 网络波动（过程态） 琥珀色状态行显示「正在自动重试 n/5」，最多 5 次；恢复后绿色小字提示，从断点继续写作，不重写已写内容。
7⛔ 错误态（红色卡片） 重试 5 次仍失败 → 红卡报错并保留进度；API Key 等鉴权/配置错误不重试，请求直接以红卡返回。红卡含错误码与操作按钮。
