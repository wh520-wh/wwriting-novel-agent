点得出来的东西

  1. 厂商大全不是主列表。左列只装你添加过的供应商（首启按目录播种 2 条：DeepSeek、小米 MiMo）。其余 8 家在「添加供应商」里，带搜索。这就是「90 个用不上的别堆在列表里」。
  2. 模型列表默认是空的。选中「智谱 GLM」看这个状态：只有一个「添加模型」虚线行，没有解释段落。点它弹出候选池（可搜索），或直接输入模型 ID。
  3. 接入地址与协议是锁定行。带锁图标、灰底、不可编辑；要改就走「中转站 / 自建服务」。
  4. 整条流程没有「密钥存储名」。要你填的只有密钥本身。
  5. 一个按钮说清下一步。没密钥时它写着「先粘密钥」且是灰的；粘上变「连接」；在途变「正在连接…」；已配好且输入框为空时它变成「测试连接」。
  6. 状态齐全。列表加载骨架屏、搜不到厂商、401 红色行内错误、按钮按压位移、拉取模型的在途转圈。
  7. 草稿保护（D11/D12）。随便哪个输入框打字，底栏出现「未提交的更改」；点「关闭」弹确认层。标题与按钮是这个分区专属的，不再是写作参数那套。

相比上一版删掉的字符串（「不写也不会做错」）

  1. 引导段整段：挑一个厂商，粘上你自己的 API 密钥就能用。厂商的接入地址与模型清单我们已经内置好了。
  2. 分区标题 模型设置——左侧导航已经点着它了。
  3. 步骤条 选厂商 › 粘密钥 › 选模型——流程由控件状态表达，不由文字复述。
  4. 已经连上了。下面可以加模型、停用或设默认。
  5. 中转站和自建服务走这条路：四个字段，加一个模型 ID。
  6. 内置值，不用你填。要改就走左边的中转站入口。——锁图标已经说了。
  7. 接入地址与协议来自内置目录，已锁定。密钥保存在本机。整块删除。
  8. 还没有模型。下面填一个模型 ID 就能用。——空态只剩动作。
  9. 模型 ID 由厂商定义。不确定就先点「拉取模型」从端点列一遍。——候选池直接给。
  10. 已经替你起好了名字，想改就改。不需要你发明任何 ID。
  11. 以 http:// 或 https:// 开头。——占位符与行内错误各自承担一半。
  12. 选错只会连不上，不会写坏数据。换一个再试就行。
  13. 就填这一个，不用管什么环境变量名。——说「没有环境变量名」等于把它请回来。
  14. 更改即时生效——换成真状态 未提交的更改。
保留的唯一一句自述文案是密钥框下的「只保存在本机」：它是安全事实而非自我说明，删掉会让人不敢粘自己的 key。
