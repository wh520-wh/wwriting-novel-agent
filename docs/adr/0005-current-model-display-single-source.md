# 当前模型信息显示单源

所有「当前模型」显示面（composer 模型按钮、抽屉「模型配置」面板）统一消费同一份模型档案（buildModelProfile / dashboard effective），格式统一为「厂商 / 模型名」（如 `DeepSeek 官方 / deepseek-v4-flash`）；composer 不再从供应商清单另推显示串，模型选择器的选项标签同格式。设置页模型行是编辑器（裸名字输入框），不套显示格式。档案同时携带上下文窗口与最大输出（缺省口径与运行时同一解析函数），显示面据此展示「上下文 256k · 最大输出 64k」。一处配置变更处处同步，收口 M5 记录的三路取数、两种格式并存。
