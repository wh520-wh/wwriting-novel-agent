# 模型上下文窗口以配置字段为唯一权威

模型名（model_name）只当标识符用：用户填什么就原样发给提供方，不携带任何配置语义。有效上下文窗口唯一来自模型记录的 `context_window` 字段（缺省 256k），最大输出唯一来自 `max_output_tokens` 字段（缺省 64k，随请求作为 `max_tokens` 发送）。历史上用模型名尾部 `[1m]` 标记表达 1M 窗口的机制整体淘汰：存量名字在 store 规范化时一次性剥离尾标（含 `[1m]` 且未显式配窗口的写 1,000,000），剥后名字与此前后端实际发出的基础 ID 逐字节一致，线上行为零变化。理由：把配置藏进标识符是三处显示口径打架的病根；配置归字段、标识符归标识符之后，显示、事件、请求三方自然同源。
