# Competitive Research: 国内独立（非平台官方）AI 长篇写作工具

- 日期：2026-08-24；模式：**Standard**（6 家竞品，direct 4 + adjacent 2，每家至少 1 个一手来源）
- 决策问题：国内独立（非平台官方）AI 长篇写作工具在功能与商业化上已做到什么程度？WWriting 的"本地文件夹 + 自带 API Key + agent 自主工作流"相对它们差异化是否可感知？哪些能力是网文作者眼中的 table stakes？
- 证据边界：纯案头调研，未实测任何产品。墨狐官网为纯客户端渲染 SPA（无 SSR），取证方式为其官方站自己分发的构建产物内嵌文案；岱宗与墨狐的具体价格数字均为登录后动态加载，未能核验（见 Research Limits）。

## Executive Conclusion

国内独立 AI 长篇写作工具已经是一个**商业化成熟、形态高度收敛**的市场：六家里有四家（墨狐、笔灵、蛙蛙、岱宗）做"大纲→章纲→分章续写→润色"的向导式长篇流程，全部以**字数/点数/平台币计量 + 会员订阅**变现 [E3][E5][E7][E10]，其中三家已把客户端铺到 Windows/iOS/Android 全端 [E7][E8][E9]。WWriting 的三个差异点中：

1. **自带 API Key + 无计量计费**——真实且可感知，但只有放在竞品的计价体系旁边才可感知：笔灵终身会员也只赠 50 万 AI 字数、用完另购字数包 [E5]；蛙蛙按"蛙币"逐次扣费、无限月卡 ¥213/月 [E7]；岱宗用"岱宗平台货币 🪙"按量扣费 [E10]。WWriting 的"用自己 Key、成本只等于 token 单价"在这个市场里是结构性差异，不是功能差异。
2. **本地文件夹 + 数据归属**——同样结构性，且与三家云端同步产品形成对照 [E6][E9][E12]；蛙蛙需专门承诺"不把作者内容用于 AI 训练"来补信任 [E6]，恰好说明云端归属是该市场的真实焦虑。
3. **agent 自主工作流**——**正在被追平**：岱宗已经自我定位"写作圈的 Cursor"并内建故事圣经 + 滚动摘要 + 知识图谱三层记忆 [E9]，蛙蛙的"智能蛙（小说 Agent）"已进入公测、宣称"30+ 作品数据自动拉取、生成内容始终贴合主线" [E7]。"agent"这个词本身已不是差异化。

**最大风险不在架构，在供给侧**：网文作者第一眼评判的是内容资产——热门脑洞、起名器、题材素材库、拆书、100+/5000+ 生成器与工具广场 [E2][E4][E6][E7]。这四家 direct 竞品全部重兵布防此处，WWriting 目前只有一个"避免 AI 腔"技能对上了"去 AI 味"这一项 [E1]。差异化楔子（wedge）成立的前提，是先把供给侧 table stakes 用 WWriting 已有的 SKILL.md 插件体系低成本补齐（P0），再谈"本地 + 自带 Key"的对比叙事。

## Current Product Baseline

均为仓库内已核对事实（v0.5.0，README + 源码结构）[E1]：

| 维度 | 现状 |
|---|---|
| 形态 | 本地 Electron 桌面应用，打开任意文件夹即聊天 |
| 工作流 | 单一 ProjectAgent 内核：聊天/写作/审核同一对话面，模型自主读文件、调工具、写章节，Visible Plan + 队列 + 立即/停止 |
| 一致性/记忆 | WWRITING.md 项目记忆（可查看可手编）+ memory/ 章节索引摘要 + checkpoints/ 阶段快照 + 章节版本快照（200 版上限） |
| 素材/模板 | 内置 12 个 SKILL.md 写作技能（含"避免 AI 腔"，对上竞品"去 AI 味"）；**无**灵感库/起名器/题材素材库/拆书 |
| 模型 | 自研 ModelGateway，兼容任意 OpenAI 兼容网关，API Key 仅存本机；预设 DeepSeek、MiMo |
| 计费 | 无会员/点数；成本面板记录 token 与成本估算 |
| 导出/归属 | 章节即本地 Markdown；"导出成书"确定性本地流程，不过模型 |
| 桌面端 | Windows 10/11（Electron） |

## Cross-Market Patterns

**Table stakes（网文作者视角，四家 direct 全部具备，缺了会被第一眼判死）：**

1. 向导式"大纲→章纲→分章续写→润色"流程 [E2][E4][E6][E9]
2. 内容供给侧资产：灵感/热门脑洞、起名器、题材素材库、生成器集市 [E2][E4][E6][E7]
3. 拆书（爆款规律分析）[E4][E6][E7]
4. 去 AI 味/降 AI 痕迹 [E4][E7]（WWriting 的"避免 AI 腔"技能已对上 [E1]）
5. 全端客户端 + 云同步 [E7][E8][E9]（笔灵为纯网页 [E4]）

**市场上已存在的差异化**（WWriting 不能再当成独有）：

- 长篇一致性作为卖点话术化：岱宗"第 200 章仍记得主角和伏笔""上下文压缩后千章不忘" [E9]，蛙蛙"30+ 作品数据自动拉取、始终贴合主线" [E7]
- BYO 模型密钥：岱宗免费允许填自定义模型标识与密钥 [E10]
- agent 叙事：岱宗"写作圈的 Cursor" [E9]、蛙蛙智能蛙小说 Agent 公测 [E7]

**市场缺口（无一家覆盖，WWriting 独有面）：**

- 本地文件夹即工作区、章节为普通 Markdown、确定性导出不过模型 [E1] ——其余全部为云端文档/项目模型 [E6][E9][E12]
- 计费侧无计量：不按字数/点数/平台币扣费，成本即 token [E1]，对照 [E5][E7][E10]
- 过程可见与权限边界：Visible Plan、逐输入授权、版本快照回滚 [E1]

**差异化压力测试**：为什么竞品没有把"本地 + 自带 Key"做掉？因为它们商业模式就是计量计费与云留存（会员/蛙币/平台币），本地化 + BYO Key 会拆掉收入结构——岱宗允许自带 Key 但仍把它框在"写作计划权益范围内"与平台币体系中 [E10]。所以这个楔子短期不会被正面复制，但它的可感知性依赖对比陈列：作者在竞品页面看到的是"赠 50 万字" [E5]，在 WWriting 看到的必须明确是"无字数概念"。

**Non-goal（明确不做）**：不做会员/点数/字数包计费墙，不做投稿/分发/稿费平台（蛙蛙式变现闭环 [E7]），不追求"10 分钟万字、一键全篇"的速度话术 [E4][E7]，本阶段不做移动端。这些是商业模式选择，不是能力缺口。

## Prioritized Roadmap

### P0

- **R1 网文供给侧技能最小集**：用现有 SKILL.md 插件体系（而非硬编码功能）补齐 table stakes 中最显眼的缺口——"热门脑洞→大纲→章纲"模板技能与"起名 + 设定生成"技能，让 agent 在对话中按需调用、产物直接落盘 drafts/。竞品证据：墨狐起名/脑洞/场景描写 [E2]、笔灵 100+ 小说生成器与素材库 [E4]、蛙蛙 5000+ 工具广场 [E6][E7]；WWriting 技能体系基线 [E1]。验收信号：内置技能目录新增 ≥2 个网文供给侧技能，且新会话仅用自然语言"给我一个玄幻热门脑洞并起 5 个角色名"即可完成、产物在工作区文件夹可见。
- **R2 差异化对比陈列与迁移路径**：README/官网增加"数据归属与计费"对照小节（本地文件夹 vs 云端同步、无字数计量 vs 蛙币/字数包/平台币、自带 Key vs 会员权益），并验证"竞品导出 txt 拖入即可继续写"的零配置迁移。证据：竞品计费与云归属 [E5][E6][E7][E10][E12]，WWriting 本地基线 [E1]。验收信号：README 出现该对照小节；用一份竞品导出文本在空文件夹打开后 0 配置可发起第一条写作指令并通过手工验收记录。

### P1

- **R3 记忆可见性面板**：把 WWRITING.md/memory 的项目记忆做成作者可浏览的"人物/地点/伏笔清单"视图。岱宗已把同类能力产品化为档案图谱并作为首要卖点 [E9]，蛙蛙用"30+ 数据自动拉取"话术 [E7]；WWriting 数据已在本地 [E1]，缺的是展示面。验收信号：面板可列出从项目文件提取的人物与未回收伏笔条目，且续写某一章时引用清单条目可在会话中追溯。
- **R4 拆书技能**：对本地 txt/epub 生成大纲与节奏分析的技能，写入 drafts/ 供 /init 索引。三家竞品均以拆书获客 [E4][E6][E7]。验收信号：对一个 ≥10 万字本地文本运行拆书技能，产出大纲 + 节奏标注文件且不修改原文件。

### P2

- **R5 导出预设与自有 Key 成本叙事**：导出预设增加主流平台章节格式；成本面板按用户自填 Key 单价展示每章估算，把"无计量计费"变成数字对比。证据：竞品计量计费 [E5][E7][E10]、WWriting 确定性导出与成本报告基线 [E1]、蛙蛙投稿闭环反证格式需求 [E7]。验收信号：导出预设列表 ≥2 种平台格式；成本面板对样例章节显示基于自填单价的金额估算。

## Research Limits and Next Validation

- **价格数字缺口**：墨狐会员（月/季/年卡 [E3]）与岱宗"写作计划/按量套餐"（平台货币 [E10]）的具体金额均为登录后动态加载，官网静态内容无数值——两家定价 **unverified**；秘塔写作猫价格在登录墙后，主站还挂"系统升级中"横幅（2026-08-24 观测）[E12]，**unverified**。
- **墨狐取证方式特殊**：inkfox-ai.com 为 Nuxt SPA（`data-ssr="false"`），Wayback 19 个快照均为 Common Crawl 无正文；本报告证据取自其官方站分发的构建产物内嵌文案（/_nuxt/*.js），非渲染页面，可能有少量文案与线上 UI 不同步。apex 域名证书 2026-08-24 已过期（www 子域正常）；搜索结果显示的开发主体（北京云泥）与官方文案署名（深圳市云泥科技有限公司 [E2]）不一致，以官方文案为准。
- **岱宗文脉与岱宗写作的关系**为 inference [E13]：dznovel.top 主站证书过期无法直接核验，仅能由 daizongxiezuo.com 全量使用 dznovel.top 基础设施推断同属一个运营方。
- **讯飞智文仅取定位证据**（PPT/Word 生成 [E11]），未深入定价与功能——与长篇小说写作无交集，深挖不改变决策。
- **全部为案头调研**：未注册、未实测任何产品；"智能蛙""岱宗记忆系统"的实际效果（一致性是否真不崩）无法从官网文案判断。建议下一步对与决策最相关的两家做 hands-on 验证：岱宗写作（自带 Key 体验与记忆真实度）与蛙蛙写作（智能蛙 Agent 的自主度与蛙币消耗速率），并实测两家的导出物能否被 WWriting 零配置打开续写。
