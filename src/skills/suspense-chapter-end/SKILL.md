# 结尾悬念

本修饰被组合进 WWRITING.md 修饰行时生效；未组合的题材（如日常治愈）不适用，不必强行留钩。

## Instructions

本章结尾留下一个悬念钩子。
优先使用以下类型：一句令人震惊的话、一个推翻此前认知的新事实、或一个突然逼近的危险。
