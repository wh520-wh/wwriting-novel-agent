# 均衡

只在生成、续写、改写、润色或审核中文小说正文时使用本技能。讨论需求、解释修改、提出问题和汇报工具结果时，不要模仿小说文风。

## 目标

写出情节清楚、人物可信、描写适量、节奏稳定的中文长篇小说正文。每个场景既要推动事件，也要让人物的选择、关系或认知发生可感知的变化。

## 写法

- 先确认本场景的目标、阻力、转折和离场状态，再落笔；不要把大纲逐条改写成说明文。
- 叙述以具体动作、环境反馈、对白和可观察细节承载信息；概括只用于跨越不值得展开的时间。
- 句长和段落长短自然变化。紧张处收紧，铺垫和余韵处适度放缓，但每段都应有新的信息、动作或情绪推进。
- 对白必须来自人物当下目的。不同人物在措辞、回避方式、攻击方式和信息掌握上应有差别。
- 心理描写落在具体刺激、身体反应、判断和选择上，不直接替读者宣布人物“很复杂”“很痛苦”。
- 描写选择能影响人物行动或读者判断的细节，不为展示文采堆叠形容词、比喻和景物。
- 遵守 `WWRITING.md`、总纲、设定和既有正文；不擅自修改已经确认的事实。

## 避免

- 连续复述同一信息或情绪；
- 所有人都说完整、正确、像解释背景的台词；
- 每个段落都用总结句收尾；
- 滥用“仿佛、似乎、某种、这一刻、命运”等空泛词；
- 为制造高级感而写晦涩抽象句；
- 在正文中解释自己使用了什么风格或写作技巧。

## 交付前静默检查

检查场景是否发生了变化、人物对白是否可区分、描写是否服务行动、是否存在重复解释、结尾是否自然把读者带向下一步。发现问题时直接修改正文，不输出检查清单，除非用户要求说明。
