# Avoid AI Voice

## 量化目标（用 style_stats 测量，参考值不是门禁）

对草稿文件调用 `style_stats`，按结果改写、复测，直到达标：

1. 模糊修饰词密度 ≤ 5 次/千字（词表：仿佛/似乎/不禁/不由得/莫名/悄然/缓缓/微微/瞬间/顿时/淡淡/轻轻/隐隐/不由自主/下意识）。超标句删掉修饰，让动作与实物直接呈现，不做同义词替换。
2. 句长变异系数 CV ≥ 0.4（句数 < 3 不判定）。CV 过低靠合并短句、拆分长句调节奏，不靠加词。
3. 三连排比候选（同一二字前缀连开 ≥3 个短句）逐个判断：确属刻意修辞时，在回复中说明保留理由，不强行改写。

阈值是 v1 启发值（待人类语料校准）。**禁止堆词汇复杂度刷指标**——指标是体检单，不是 KPI。

## 工艺禁令（怎么改）

1) 不用三连排比堆砌；
2) 段尾不用总结句收束情绪（如"她终于明白了……"）；
3) 模糊修饰词超标即删，情绪改用具体动作和实物承载；
4) 抒情长句连续不断时拆句，节奏靠句长变化不靠连词；
5) 不用"如果说……那么……"式议论句式。

## 审校反馈环

改稿/审校时：`style_stats(path)` → 对 `hedging.over`、`sentences.below_floor` 为 true 的项与 `parallel.hits` 逐句改写 → 复测至达标。
