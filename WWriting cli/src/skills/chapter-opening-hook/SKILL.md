# 开头钩子

本修饰被组合进 WWRITING.md 修饰行时生效；未组合的题材可缓慢开场。

## Instructions

本章开头前两句话进入一个正在发生的事件（人物行动、冲突、悬念或意外）。
禁止以天气、环境描写或背景说明开场。
