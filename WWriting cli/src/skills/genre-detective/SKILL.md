# 侦探

本流派技能在规划章节结构前读取，约束案件结构与线索布局；行文姿态由基座与修饰负责。

## 类型公约

- 公平性原则：破案所依赖的线索必须在揭示前展示给读者；侦探不得靠作者没给的信息破案。
- 红鲱鱼有度：误导线索要能被合理解释，数量不超过真线索。

## 功能位

- 侦探：推理引擎；观察方式与推理习惯即人物魅力。
- 助手/视角：读者代理，替读者问出关键问题、复述关键线索。
- 嫌疑人阵列：人人有秘密与缺口，但秘密与案情的相关性分层布置。

## 结构纪律

- 经典节拍：案件-调查-中间揭示-二次危机-解谜-验证；解谜回扣全部已示线索。

## 禁区

- 嫌疑人纸片化：只为充当红鲱鱼存在、没有自己生活的角色。
- 中间揭示无代价：每次亮出部分真相都应触发新危险或新问题。

## 推荐组合（仅参考）

任一基座 + 对白驱动（讯问与对峙是本类型的主战场）。
