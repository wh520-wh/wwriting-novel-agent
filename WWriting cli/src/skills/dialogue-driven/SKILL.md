# 对白驱动

本修饰与基座技能组合生效。只在生成、续写、改写、润色或审核小说正文时使用。对白质量规则（人物声音区分、不重复已知信息）见 dialogue-not-summary 手艺技能；本修饰管占比与功能。

## 生效规则

- 交锋、试探、谈判、讯问、信息交换优先用对白完成；不用叙述概括本可以演出来的交锋。
- 每轮对白至少推进一样：信息、关系、局势或筹码。
- 长对白用动作、表情、环境反馈穿插打断，避免乒乓球式连续空转。
- 叙述为对白服务：交代、转场、氛围用最短叙述完成，篇幅留给交锋本身。

## 避免

- 用叙述概括对话内容（「他们商量了许久，最终达成一致」是偷懒）。
- 对白轮次空转：说了十轮，信息、关系、局势一样没变。
- 人人一个腔调，对白不区分人物。
