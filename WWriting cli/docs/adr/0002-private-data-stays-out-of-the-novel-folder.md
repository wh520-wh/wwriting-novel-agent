# 私有数据只进应用私有目录，创作目录只由模型经权限确认后写入

会话、事件日志、投影缓存、成本、配置与 API Key 一律放在
`%APPDATA%\WWriting\`。创作目录（用户选的那本书的文件夹）里只有作品本身——
模型想往里写一个字，都要先过权限确认。

**Consequences**

- 创作目录是可交付、可备份、可拿去别处打开的；应用私有数据不污染它，也不随它迁移。
- 已落成断言：`scripts/smoke-windows.ps1` 有一步「数据边界」专门检查创作目录里
  没有事件日志、投影缓存、会话锁、配置，也没有私自生成的 `WWRITING.md`。
- 由此推论：**API Key 只在本机**，不进创作目录、不进版本库。环境变量
  `DEEPSEEK_API_KEY` 优先于配置文件，但它的来源（`apiKeySource`）必须一路传到
  用户看得见的地方——不说出来，用户永远查不到自己用的是哪把钥匙。
- 这条同时是「不要把功能产物写进创作目录」的判据。设计任何新功能时先问：
  它产生的东西属于作品，还是属于应用？后者不许落在创作目录。
